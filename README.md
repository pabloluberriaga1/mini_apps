# mini_apps

Esta carpeta es a modo experimental, voy a ir compartiendo una colección de apps pequeñas para resolver problemas o situaciones del dia a día. Cada una surge de una necesidad real: automatizar algo tedioso, simplificar un flujo de trabajo, o crear una herramienta para algun problema general.

Mayormente son proyectos web vanilla (HTML/CSS/JS), sin dependencias grandes. Algunas usan servicios externos como Firebase o Google Workspace.
